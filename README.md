# Health & Wellness App

This repository is for managing the development and deployment of the Health & Wellness Support App, a cross-platform mobile application aimed at improving access to health resources, mental health tools, and emergency medical services in urban, township, and rural communities.

## Project Overview

The project is managed by a team of four members:
- **Lerato** – UI/UX Design & Testing
- **Molatelo** – Front-end & Back-end Development
- **Thipe** – Database & Deployment
- **Kundayi** – Documentation & Outreach

- Milestones: Phase 1, Phase 2, and Phase 3

## How to Contribute

1. Clone the repository
```bash
git clone https://github.com/your-org/health-wellness-app.git
```
2. View tasks in the [Projects Tab](https://github.com/your-org/health-wellness-app/projects)

3. Check assigned issues and create pull requests to resolve them
